Privacy policy

Last updated: 27 September 2026

Who uses it

Tech Shorts is a personal tool used by one person, its owner, to upload their own videos to their own YouTube, Instagram and Facebook accounts. No one else can sign in to it.

What it accesses

With the owner's permission it uses the YouTube Data API to upload videos to the owner's channel and to read that channel's basic details. It doesn't read, collect or store data about any other person.

Where data is kept

The sign-in token that allows the uploads is stored only on the owner's private home server. It is not shared, sold, or sent anywhere except back to Google to make the upload. The tool has no analytics, ads or tracking.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions.

Tech Shorts' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
